## 3. v1 failure is a PowerShell $Matches collision

The original v1 verification failed because of a PowerShell $Matches collision. It did not identify a header mismatch.

header_rehash_verification.txt records HEADERS_MATCHED: System.Collections.Hashtable and HEADER_REHASH_RESULT: FAIL. It also records HEADERS_MISMATCHED_OR_MISSING: 0. System.Collections.Hashtable is the PowerShell automatic $Matches variable rendered as a Hashtable, not a header count. v2 states that it supersedes an incomplete v1 verification caused by a PowerShell variable collision.

v1 contains no per-header MATCH line. It contains no path and no header digest that could support a mismatch finding. The v1 FAIL is a summary-field defect. This acceptance does not treat that FAIL as evidence that any header differed from include_hashes.txt.
