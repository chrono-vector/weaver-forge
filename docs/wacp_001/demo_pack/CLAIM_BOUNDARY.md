# Claim Boundary

This WACP pack is a deterministic, bounded extraction of declared repository context for the stated scope manifest, base/head pair, review mode, repository identity, and generator version.

WACP does NOT:

- authorize changes
- prove correctness
- prove safety
- prove completeness
- establish independent verification
- establish Human Final
- promote evidence
- grant production permission
- prove excluded files are irrelevant
- prove selected files are sufficient
- prove tests passed unless WACP actually executed and recorded them
- replace repository inspection
- replace reviewer judgment
