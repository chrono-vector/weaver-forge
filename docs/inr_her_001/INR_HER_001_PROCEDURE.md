# INR-HER-001 Phase 1 procedure

Phase 1 is a local fail-closed check of supplied r4 evidence. It is not an external run, not Independent Witness admission, not a Human Final, not production authority, and not a FULL INR PASS.

The bounded question is protection of P from the restricted child principal U. This phase does not establish that predicate. Exclusion of writers outside the declared trust base T stays UNCONFIRMED. Records produced by the HER controller are not independent external witness evidence.

## Ceiling

`all_writer_isolation_bounded_v1` cannot be PASS. `phase1_ceiling` is `ISOLATION_PASS_UNAVAILABLE`.

A complete synthetic Windows event is BLOCKED `HER_PYTHON_PIN_PENDING`. That reason outranks the unratified MinGit pin. `her_surface_hash_agreement` may be PASS with reason `HASH_AGREEMENT_ONLY` when the supplied freeze and post digests match the code-owned T digest. That reason is hash agreement only.

Python 3.11.9 SHA-256 stays `PIN_PENDING`. The MinGit digest stays `UNRATIFIED`. No authenticated pin is stored in this phase. Privileged token, Job, ACL, and Git-ownership observations stay `UNVERIFIED` because this phase does not create them.

## Modules

- `validate_her_v1.py` checks the four role schemas with the accepted `schema_check` vocabulary. Every const has a type.
- `supervisor_her_v1.py` evaluates supplied evidence. It does not launch a child and it does not open `docs/inr_001/supervisor_inr_v0.py`.
- `collect_bundle_her_v1.py` writes a mutable export outside P. Submitting that export to the r4 verifier is BLOCKED `HER_SCHEMA_VERSION`.

Schema ids are `inr.event.v0.r4`, `inr.supervisor.result.v0.r4`, `inr.her.surface_record.v0`, and `inr.her.predicate_result.v0`. An r3 schema version is BLOCKED `HER_SCHEMA_VERSION`.

If an isolation predicate would require an edit to the accepted r3 supervisor, the result is BLOCKED `HER_SUPERVISOR_EDIT_REQUIRED`. Phase 1 does not make that edit.

## Evidence that must not pass

Missing surface records stay UNCONFIRMED `HER_SURFACE_RECORD_ABSENT`. Runner flags stay UNCONFIRMED, and a flag that claims PASS is FAIL `HER_CONTRADICTION`. Historical r3 origins stay on the historical predicate. Forged origins are FAIL `HER_FORGED_EVIDENCE`. A granted U write is FAIL `HER_U_WRITE_GRANTED`. Live checkout Git, or extra snapshot entries, is FAIL `HER_GIT_SOURCE_NOT_SNAPSHOT`.

T is the ten code-owned sentences in `TRUST_BASE`. P is not a member of T. The nine `surface_role` values are the Phase 1 protected set, including ledger.

## Out of scope

No GitHub workflow is created or run. Accepted INR-AWI-001 / r3 sources, verdicts, schemas, and the Human Final stay byte-for-byte.
